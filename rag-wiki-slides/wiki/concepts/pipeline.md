# RAG Pipeline

1. **資料準備：** 取得並整理文件。
2. **索引建立：** 文件分塊、轉 embedding、放入向量索引。[S2][S3]
3. **使用者提問：** 將問題轉為 query 表示。[S2]
4. **Retriever：** 找出相關文件或段落。[S1][S5]
5. **Generator：** 在檢索上下文的條件下生成回答。[S1][S5]
6. **答案驗證：** 確認引用是否真的支持回答（教學設計延伸）。

**來源：** [S1](../../raw/S1.md)、[S2](../../raw/S2.md)、[S3](../../raw/S3.md)、[S5](../../raw/S5.md)
