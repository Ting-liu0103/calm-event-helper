# 需求釐清：先討論、後生成

本文件依 HW10 題目與先前選定的 RAG 主題整理成 **需求草案**，不是冒充已完成的 8–10 題真人訪談。老師要求的「先讓 AI 訪談、使用者確認後才建檔」可由使用者確認此摘要並附對話截圖補強。

| 訪談問題 | 本次建議需求 |
|---|---|
| 1. 讀者是誰？ | 沒有 RAG 經驗的大學生 |
| 2. 想回答什麼？ | RAG 是什麼、embedding、FAISS、retriever、generator、限制 |
| 3. 來源類型？ | 1 篇原始論文、4 份技術／模型官方文件 |
| 4. 語言？ | 繁體中文，必要術語保留英文 |
| 5. 出處要多細？ | 每個 Wiki 概念和投影片標 [S1]–[S5]，附原始 URL |
| 6. 資料矛盾怎麼辦？ | 不擅自合併，標出來源差異；證據不足則不下結論 |
| 7. 每次 ingest 幾篇？ | 先 1–2 篇，確認索引，再逐批累積至少 5 篇 |
| 8. 最後要產出什麼？ | 可瀏覽 Wiki、12 張教學 HTML 簡報、graph、檢查報告 |
| 9. lint 檢查什麼？ | 來源數、引用、頁數、HTML 結構、來源網址、互動控制 |
| 10. 如何停止？ | 最多修 3 輪；資料不足或無法支持主張就停止生成該主張 |
