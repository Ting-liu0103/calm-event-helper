# SKILL.md — topic-slides Loop 規格

**觸發：** Wiki 來源或投影片文案更新後。

**目標：** 使用 Wiki 產生 8–15 張可瀏覽的 HTML 教學簡報。

**限制：** 只能引用 Wiki／證據卡中已有的事實；不得在 HTML 渲染階段新增知識或數字。

**完成標準：** `python3 scripts/lint.py` 零錯誤；每頁有來源標記或自製示例註記；引用 URL 有效（連線檢查另列）；桌機與手機實際開啟沒有遮擋；獨立審查通過（若有執行）。

**檢查：**
1. 程式檢查：5 來源、8–15 頁、來源代號存在、連結與 HTML 基本結構。
2. 內容檢查：來源是否真的支持投影片敘述、是否說反、有無未標示的假設。
3. 視覺檢查：頁面是否溢出、前後翻頁、鍵盤操作、手機版。

**每一輪：** 只修檢查報告列出的問題，不要重新生成整份內容。文案最多局部重試 2 次；渲染最多 3 次。

**停止：** 全部已執行的關卡通過，或累積 3 次修改仍未通過；若相關資料少於 3 份或關鍵主張無來源，停止該部分並標註不足。

**審查分工：** 寫作者與獨立 AI 審查者應分開對話，後者只能看到最終稿與來源，不能自行改檔。
