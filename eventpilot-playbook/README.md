# EventPilot Playbook｜活動企劃知識卡

AI 課程第九週作業。

這個專案的核心不是只做一頁網站，而是透過 `AGENTS.md` 建立可以重複使用的開發規則。之後 AI 只要依照規則在 `data/guides.js` 新增資料，就能自動延伸首頁卡片與共用詳細頁。

## 特色

- 可搜尋與分類活動指南
- 所有詳細內容共用 `guide.html`
- 新增一般內容不需要複製 HTML
- `AGENTS.md` 規範命名、資料格式、文案、UI 與 QA
- 可直接放到 GitHub Pages
